帝可得

IoT智能售货机后台管理平台，基于若依二次开发，覆盖点位、设备、订单、工单全业务闭环。

SpringBoot RuoYi若依 MyBatis-Plus IoT设备对接

项目简介

帝可得是面向自动售货机运营商的物联网后台管理系统，基于若依框架二次开发，实现点位管理、设备管控、商品库存、合作商、运维工单、订单交易、策略配置完整业务闭环。对接售货机IoT设备，完成设备状态上报、库存预警、补货工单自动生成、微信支付宝支付，模拟真实物联网项目开发流程，学习权限、分布式锁、接口幂等、业务工单流程等企业级开发能力。

核心功能

点位&合作商管理

区域点位维护，合作商信息管理，统计点位设备数量

设备管理

售货机设备接入，设备状态监控、投放、撤机管理

商品与库存

商品维护，设备库存管理，库存不足自动预警

运维工单

补货、维修工单创建派发，接单、完成、拒绝全流程

订单&支付

用户扫码下单，微信、支付宝支付，订单统计查询

权限人员管理

角色权限，运维人员账号，密码重置，数据权限控制

技术栈

Java SpringBoot MyBatis-Plus RuoYi若依 MySQL Redis Vue2 Knife4j 微信/支付宝支付 IoT设备对接

项目亮点

  • 基于若依快速开发平台二次开发，理解企业后台权限体系
  • 完整工单业务流程，状态流转，防止重复接单并发问题
  • 接入第三方支付，理解支付回调、订单状态处理逻辑
  • 模拟物联网设备上报，设备、库存、订单业务联动
  • MyBatis-Plus快速CRUD，代码生成器，简化重复开发
  • 真实商用业务场景，适合简历中企业后台/IoT项目展示
