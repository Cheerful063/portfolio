黑马点评

Redis高并发实战项目，探店点评社交平台，解决缓存、秒杀、分布式业务场景。

SpringBoot Redis Lua脚本 高并发

项目简介

黑马点评是基于Redis实现的探店点评社交后端项目，模拟大众点评业务。实现商户查询、用户登录、探店笔记、点赞收藏、关注粉丝、优惠券秒杀等模块。重点练习缓存穿透、缓存击穿、缓存雪崩、分布式锁、Lua脚本、Stream消息队列等高并发场景解决方案，是Java后端Redis经典实战项目。

核心功能

短信登录

手机号验证码登录，Redis维护登录状态

商户查询

商户缓存，分类搜索，距离排序

点赞收藏

笔记点赞、收藏、点赞排行榜

关注粉丝

用户关注，关注推送，粉丝列表

优惠券秒杀

秒杀扣库存，一人一单，分布式锁

探店笔记

发布笔记，图片上传，滚动分页

技术栈

Java SpringBoot MyBatis MySQL Redis Lua脚本 Redis Stream Redisson Maven Vue

项目亮点

  • 处理缓存穿透、缓存击穿、缓存雪崩三大缓存问题
  • Redisson实现分布式锁，解决超卖、一人一单并发问题
  • Lua脚本保证多条Redis命令原子执行
  • Redis Stream实现消息队列，异步处理秒杀订单
  • Geo地理位置实现附近商户查询，ZSet实现点赞排行榜
  • 基于Redis实现登录会话，滚动分页优化大列表查询
